# Blender NodeMode

Custom Blender builds and source code. Download Windows, Linux, or source packages from [Releases](https://github.com/cgmatter/NodeMode/releases/latest).

For source builds, extract the whole ZIP and follow BUILDME/README.txt. macOS users can build from source on Apple Silicon; no prebuilt macOS package is available.

Blender NodeMode is based on Blender 5.4 Alpha. Licenses and third-party notices are included in each package.
